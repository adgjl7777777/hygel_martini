--------------------------------------------------------------------------------
1. 개요 (INTRODUCTION)
--------------------------------------------------------------------------------
쯔비터 이온 하이드로젤의 복잡한 화학적 성질과 방대한 N-mer 조합(188개 이상)을 
효율적으로 처리하기 위해, 본 프로젝트는 '속도'와 '정밀도'를 선택적으로 사용할 수 있는 
이원화된 하이브리드 워크플로우를 채택한다.

사용자의 피로도를 최소화하고 즉각적인 결과물을 내기 위해 [Fast Mode]를 최우선으로 구현한다.

--------------------------------------------------------------------------------
2. 워크플로우 분리 (DUAL-MODE ARCHITECTURE)
--------------------------------------------------------------------------------

[MODE A: THE GOLDEN PATH (PRECISION)]
- 엔진: ORCA 6.1.1 + TorsionDrive + Wavefront Propagation
- 흐름: N-mer 생성 -> ORCA 최적화/스캔 -> RESP2(0.8 스케일링) -> OPLS-AA itp -> AA-MD -> Martini Fitting
- 강점: 논문급 정밀도, 쯔비터 이온의 강한 정전기적 상호작용 완벽 묘사.
- 약점: 계산 자원 대량 소모, 시간 오래 걸림.

[MODE B: THE WARP DRIVE (FAST)] - ***CURRENT PRIORITY***
- 엔진: xTB (GFN2-xTB) + Bartender (Martini 3.0 auto-generator)
- 흐름: N-mer 생성 -> xTB 구조 최적화 -> Bartender 직통 Martini 파라미터화 -> 검증
- 강점: 압도적인 속도 (모노머당 수 초~수 분), 즉각적인 전체 시스템 구축 가능.
- 약점: 쯔비터 이온(SO3-)의 PES 묘사 정확도가 정밀 모드 대비 다소 낮음.

--------------------------------------------------------------------------------
3. 세부 구현 계획 (DETAILED IMPLEMENTATION)
--------------------------------------------------------------------------------

STEP 1: [Smart Caching System]
- 모든 N-mer 시퀀스에 대해 고유 해시(Hash) 부여.
- 이미 결과가 존재하는 경우 (itp/gro 파일 존재), 모든 중복 계산을 0.1초 만에 스킵.

STEP 2: [xTB-Bartender Fast-Track]
- `parameterize/xtb_runner.py` 생성: ASE를 이용해 xTB 최적화 수행.
- `parameterize/bartender_wrapper.py`: xTB에서 나온 구조와 전하를 Bartender 입력으로 변환.
- Martini 3.0 비드 타입 자동 할당 로직 연동.

STEP 3: [Parallel Execution Control]
- 사용자가 지정한 `MAX_CORES` 내에서 병렬화.
- 예: 188개 작업을 4개씩 묶어 동시에 xTB-Bartender 가동.

--------------------------------------------------------------------------------
4. 사용자 인터페이스 (CLI USAGE)
